# Metadata column description of objects
## Dataset Overview
The GEO repository (accession to be provided) contains processed single-cell RNA-seq data in Seurat object (.rds) and Anndata format (.h5ad).  
Discovery cohort samples of pbmc_final include kidney transplant recipients (mRNA-1273 vaccine responders and non-responders) and healthy controls, 
collected pre- and post-vaccination.

## The following metadata is included:
| Column            | Description |
|-------------------|-------------|
| CellType          | Major annotated cell type (e.g., monocytes, T cells, B cells, NK cells) |
| sub_Cell_Types    | Annotated monocyte subtypes (e.g., classical, non-classical, intermediate) |
| condition1        | Vaccine status condition (pre-/post-vaccination) |
| condition2        | Vaccine response condition (responder, non-responder, healthy control) |
| harmony.cluster   | Cluster assignments after batch correction using Harmony |
| seurat_clusters   | Unsupervised cluster assignments generated by Seurat |
| leiden            | Cluster labels from scVI re-clustering |
| nCount_RNA        | Total UMI counts from RNA assay per cell |
| nFeature_RNA      | Number of detected RNA features (genes) per cell |
| nCount_ADT        | Total counts of antibody-derived tags (ADT, CITE-seq features) per cell |
| nFeature_ADT      | Number of detected ADT features per cell |
| nCount_HTO        | Total counts of hashtag oligos (HTO, for cell hashing / multiplexing) per cell |
| nFeature_HTO      | Number of detected HTO features per cell |
| percent.mt        | Percentage of counts mapped to mitochondrial genes (QC metric) |
| patientID_pre_NR  | Identifier of pre-vaccine non-responder donor |
| patientID_pre_R   | Identifier of pre-vaccine responder donor |
| patientID_post_NR | Identifier of post-vaccine non-responder donor |
| patientID_post_R  | Identifier of post-vaccine responder donor |
| HC_ID             | Identifier of pre-vaccine healthy donor |
| Vac_HC_ID         | Identifier of post-vaccine healthy donor |
| HC_country        | Country of origin of healthy donors |
| HC_region         | Geographic/ethnic background of healthy donors (e.g., Caucasian, Asian) |
| orig.ident        | Original identity of the sample (batch or donor source) |
| sample            | Donor/sample identification |
