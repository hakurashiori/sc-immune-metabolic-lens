# Assessment of NR signatures and metabolic rewiring in immunocompromised populations

## The dataset includes the following metadata:
| Column name                   | Description                                                                                                                                                                                                                                             |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GEO #`                       | GEO accession number of the original public dataset.                                                                                                                                                                                                    |
| `Sample`                      | Study-defined sample ID assigned to each unique donor in this study. These IDs (e.g., KTR1, TNBC2) are internally assigned and may differ from original dataset labels.                                                                                 |
| `IC_group`                    | Classification of immunocompromised condition (e.g., KTR, AD, CLL, LC, HGSOC, HIV, etc.).                                                                                                                                                               |
| `treatment state`             | Disease or treatment status at the time of sampling. Common values include: `UT` (untreated), `PD1`, `CT`, `ART` (treatment types such as anti-PD1, chemotherapy, antiretroviral therapy), `T-Sn`, or `NACT` (tumor stage or neoadjuvant chemotherapy). |
| `disease state`               | Disease diagnosis at the time of sample collection (e.g., CKD, SiD, AKI, HGSOC, etc.).                                                                                                                                                                  |
| `cell cnt`                    | Total number of cells retained after QC.                                                                                                                                                                                                                |
| `cell cnt after min.features` | Number of cells retained after filtering for minimum gene features (e.g., nFeature\_RNA > 200).                                                                                                                                                         |
                                                                                                                                     |
