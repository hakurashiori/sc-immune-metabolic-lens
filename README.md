# Single-cell immune-metabolic lens on immunocompromised settings

Code for the single-cell transcriptomic analysis described in the paper:  
**"A pre-existing MT-ND3-linked OXPHOS-dominant monocyte state constrains vaccine responsiveness in immunocompromised patients"**

This repository contains scripts used to analyze 10x Genomics Chromium scRNA-seq data, focusing on monocyte metabolic rewiring and its role in vaccine non-responsiveness.

---

## Data Access

Due to patient privacy and IRB restrictions, raw single-cell data are not publicly available.
Processed objects (Seurat RDS and AnnData files) will be made available upon publication through controlled-access repositories or upon reasonable request (https://doi.org/10.6084/m9.figshare.31083958), in accordance with institutional and ethical guidelines.
